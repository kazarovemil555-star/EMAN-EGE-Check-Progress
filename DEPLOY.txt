КАК ЗАПУСТИТЬ ЛОКАЛЬНО
======================
flet run --web --port 8550 main.py

КАК СДЕЛАТЬ САЙТ НЕЗАВИСИМЫМ ОТ ТЕРМИНАЛА
===========================================
Вариант 1 — GitHub Pages (рекомендуется для этой версии):
1. Загрузить содержимое этой папки в GitHub-репозиторий.
2. В GitHub открыть Settings -> Pages.
3. В Source выбрать GitHub Actions.
4. Сделать push в ветку main.
5. Workflow .github/workflows/build-deploy.yml соберёт и опубликует сайт.
6. После публикации сайт работает в интернете сам по себе: терминал и компьютер
   владельца не должны быть включены.

Вариант 2 — собрать статический сайт вручную:
flet publish main.py

После команды появится папка dist. Её можно загрузить на статический хостинг,
например Cloudflare Pages.

ВАЖНО
======
Текущие результаты хранятся в браузере (SharedPreferences / local storage).
Поэтому данные с http://127.0.0.1:8550 автоматически не перенесутся на новый
опубликованный домен. После подключения Supabase данные будут храниться в облаке
и синхронизироваться между устройствами.
